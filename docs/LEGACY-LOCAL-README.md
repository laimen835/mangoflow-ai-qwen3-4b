Прямой чат: https://grudgingly-innovative-pinscher.cloudpub.ru/widget/chat.html

Снимок кода c438abb, отдельная публикационная ветка без старой истории и .env.
Используется установленная qwen3:4b-instruct, Nomic 768, multi_query + rerank,
source_quotes. Версия модели закреплена в model-version.json. Веса модели,
база знаний, беседы, токены и приватные настройки не включены в Git.
Это публикация кода программы, а не облачный хостинг или загрузка весов.
Текущая ссылка работает через локальный гостевой шлюз и clo, пока компьютер
и соответствующие сервисы включены.

Для новой установки нужны PostgreSQL/pgvector, тот же артефакт LLM и Nomic,
проверенный индекс знаний и локально настроенная .env.local. Безопасные
параметры запуска приведены в .env.example; исходные документы и БД не
распространяются этим репозиторием. Не заменять установленную модель другим
артефактом только из-за похожего имени. Старые пути и команды в документации
ниже — история разработки; не запускать общие сервисы без сверки.

Сравнение 60 вопросов на модель: docs/APPLICANT-MODEL-COMPARISON-20261117.md.
Это не утверждение о готовности всех ответов: сохраняются проблемы поиска,
маршрутизации и уточнений. 4B выбрана за более осторожное поведение.

# СПК · Помощник студента

Локальное приложение для студентов и абитуриентов СПК СКГА. FastAPI + PostgreSQL/pgvector + Ollama. Интерфейс находится в `widget/` и работает без сборки и внешних CDN.

## Возможности

- Чат с постепенным выводом ответа, остановкой генерации и ссылками на источники.
- Общий поиск по загруженным документам и материалам ncsa.ru: векторный поиск, полнотекстовый поиск, приоритет точных кодов специальностей и групп.
- Проверенные поля контактов и директора; каталог официальных PDF расписаний.
- Справочник преподавателей с отделениями, поиском и подсказками при опечатках.
- Выбор группы, история диалогов в этом браузере, сохранение оценок ответов.
- Локальное OCR сканированных PDF: встроенный Windows OCR на русском или Tesseract rus+eng.
- Автообновление источников каждые 6 часов, пока запущен сервер, и ручное обновление с ключом администратора.
- Проверка доступности базы и установленных моделей через `/ready`.

## Запуск на настроенном компьютере

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start-local.ps1

Приложение: http://127.0.0.1:8000/
Портал: http://127.0.0.1:8000/widget/
Описание API: http://127.0.0.1:8000/docs

Для остановки API и PostgreSQL:

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\stop-local.ps1

Ollama остаётся запущенной. Скрипты рассчитаны на локальную установку компонентов в `D:\Codex-RAG-runtime`.

## Конфигурация

Параметры читаются из `.env`, затем из `.env.local`; локальный файл имеет приоритет. `.env.local` не попадает в Git. `.env.example` — шаблон без действующих паролей.

- База этой установки: PostgreSQL, порт 55432, база `rag`.
- LLM задаётся `LLM_MODEL`; модели должны быть заранее загружены в Ollama.
- Поисковая модель: `nomic-embed-text`, 768 измерений. Смена поисковой модели требует совместимой схемы и переиндексации.
- `AUTO_SYNC_ENABLED=true`, `SYNC_INTERVAL_HOURS=6` управляют обновлением в работающем приложении. Это не автозапуск Windows.
- `ADMIN_API_KEY` защищает ручную загрузку и обновление. Ключ не встраивается в JavaScript и не хранится интерфейсом.

Для подготовки Python-окружения:

    python -m venv .venv
    .\.venv\Scripts\python.exe -m pip install -r requirements-local.txt
    .\.venv\Scripts\python.exe -m alembic upgrade head

Для другой машины предварительно нужны Ollama и PostgreSQL с pgvector. При использовании исходного `docker-compose.yml` PostgreSQL опубликован на 5432 — укажите соответствующий порт в конфигурации.

## Источники

Начальная страница: https://ncsa.ru/institutes/spk/inst.php?ELEMENT_ID=148

Обновить выбранные страницы и PDF:

    .\.venv\Scripts\python.exe -X utf8 -m scripts.sync_ncsa --max-pages 16 --max-pdfs 8

Данные сайта сохраняются в существующих таблицах documents/chunks. Прежние локальные документы сохраняются. Неизменившийся документ пропускается, изменившийся обновляется без дублирования. При ошибке эмбеддингов предыдущая версия остаётся рабочей. Подтверждённые 404/410 архивируются; PDF, удалённый из единственной известной и успешно проверенной родительской страницы, тоже архивируется. Материалы за пределами выбранного обхода не объявляются проверенными.

Состояние: `logs/update-status.json`. Подробный отчёт: `logs/ncsa-sync.json`. OCR-кэш: `data/raw/ncsa-cache/ocr/`.

Свои файлы можно индексировать через `scripts.ingest_file`; обратите внимание, что исходный импортёр переносит файлы из inbox в storage.

## Проверки

    .\.venv\Scripts\python.exe -m pytest -q
    .\.venv\Scripts\python.exe -X utf8 -m scripts.evaluate_portal
    .\.venv\Scripts\python.exe -X utf8 -m scripts.smoke_local

Интеграционные тесты используют локальную базу и модель эмбеддингов. Основные тесты изолируют свои записи транзакциями; тест гибридного поиска оставляет явно помеченный тестовый документ. Набор evaluate_portal проверяет 50 конкретных приёмочных сценариев работающего API; он не является исчерпывающим измерением качества LLM. Результаты: `logs/acceptance-results.json`.

## Границы прототипа

Расписания доступны в официальных PDF, фильтр группы подбирает документ. Автоматический точный разбор всех пар, аудиторий и учебных исключений пока не подтверждён.

Числитель/знаменатель не вычисляется по календарной чётности. Для включения расчёта нужны подтверждённые колледжем `ACADEMIC_WEEK_ANCHOR`, `ACADEMIC_WEEK_ANCHOR_TYPE` и `ACADEMIC_WEEK_SOURCE`. Без них интерфейс показывает отсутствие подтверждения.

OCR может ошибаться в фамилиях, цифрах и таблицах. Некоторые страницы сайта недоступны или пусты, часть документов слишком велика для текущего лимита. Полнота сайта не гарантируется. Старые ответы диалогов помечаются как ответы прежней версии и не являются источником новых фактов.

Приложение настроено для локального использования. Публичная авторизация и размещение в интернете в эту версию не входят.


## Обновление: компактный чат

Главная страница http://127.0.0.1:8000/ — демонстрация кнопки справа снизу.
Портал сохраняется по http://127.0.0.1:8000/widget/.
Отдельный чат: http://127.0.0.1:8000/widget/chat.html.

Для встраивания в доступную тестовую страницу подключить скрипт API-сервера:

```html
<script src="http://127.0.0.1:8000/widget/embed.js" defer></script>
```

Этот адрес работает на локальном компьютере. Для реального сайта нужны размещённый HTTPS-сервер и отдельная настройка доступа; в данном этапе сайт института не меняется.

Виджет использует существующие `/api/v1/chat/stream` и историю портала. Кнопка закрытия и Escape скрывают окно, сохраняя диалог; новый диалог создаёт новый UUID. При остановке неполный ответ оформляется безопасными ссылками, но не сохраняется в серверной истории. Настройки модели и ключ администратора посетителям не показываются.

Обычные HTTP/HTTPS-адреса, Markdown-ссылки и `[1]` становятся кликабельными после генерации и при восстановлении истории. HTML модели не исполняется. Локальные вложения поддерживаются через `/api/v1/files/{id}`. Тестовые документы исключены из поиска по умолчанию; параметр `HybridRetriever(..., include_test=True)` существует только для внутренних проверок.

Поиск учитывает тему коротких уточнений из пользовательских сообщений, расширяет несколько предметных синонимов и отдельно ищет ключевой предмет вопроса. Контекст нормализует лишние пробелы и переносы слов. Факты из прежних ответов ассистента не используются как источник.

`GET /api/v1/portal/source-status` возвращает ошибки последнего обновления с официальными адресами и краткими причинами. `GET /api/v1/portal/sources` дополнен признаком `needs_verification` для OCR. База не требует миграции.

Проверки:

```powershell
.venv\Scripts\python -m pytest -q
node tests/test_answer_renderer.cjs
.venv\Scripts\python -m scripts.evaluate_quality
.venv\Scripts\python -m scripts.compare_quality_models
```

Последние два скрипта требуют работающие API, базу и Ollama. Сравнение моделей не переключает конфигурацию автоматически. Фразы и URL в автоматических проверках не заменяют ручную оценку достоверности. План расширения материалов — [docs/KNOWLEDGE-BACKLOG.md](docs/KNOWLEDGE-BACKLOG.md).

Итоги проверки и ограничения: [docs/UPDATE-2026-11-08.md](docs/UPDATE-2026-11-08.md).


## Пробный доступ через интернет

`start-share.ps1` запускает отдельный гостевой шлюз и временный HTTPS-туннель через localhost.run. `stop-share.ps1` отключает только публичный доступ. Компьютер должен оставаться включённым; постоянное размещение не настроено. Подробности и ограничения: [docs/SHARING.md](docs/SHARING.md).

## Эксперимент поиска знаний

Реализованы отдельный индекс-кандидат, локальный ONNX reranker, защищённая диагностика и понятные ответы при нехватке сведений. Кандидат не включён: контроль качества и задержки не пройден. Порядок работы и результаты: [docs/SEARCH-V2.md](docs/SEARCH-V2.md).

## Пилот по стипендиям и материальной поддержке

Добавлены проверенные материалы академии для СПО/СПК, разбор DOCX/XLSX, структурные фрагменты и исключение непроверенных документов. На четырёх подтверждённых контрольных вопросах результат вырос с 0/4 до 4/4; точные неподтверждённые суммы не подставляются. Границы результата, оставшиеся ошибки и порядок отката: [docs/SCHOLARSHIP-PILOT.md](docs/SCHOLARSHIP-PILOT.md).
