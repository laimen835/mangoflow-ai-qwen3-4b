Исправлены три причины потерь поиска/контекста:

- Для уже найденных соседних фрагментов одного документа восстанавливается только точное перекрытие при соседних индексах. Набор подтверждающих идентификаторов сохраняется, а общий лимит контекста остаётся прежним.
- Явный вопрос о содержимом главной страницы СПК ограничивается найденными фрагментами этой страницы. Вопросы о сравнении/противоречиях продолжают видеть другие документы.
- Вспомогательные синонимы больше не создают обязательный фокус-фильтр, отсутствующий в исходном вопросе. Запрос про платные места не превращается в обязательный поиск слова «стоимость».

Видимые дочерние элементы теперь разворачиваются без импорта служебных аннотаций; версия метода — `docx-smarttags-v2`. На десяти сохранённых DOCX повторное извлечение исправило четыре строки одного документа, остальные тексты не изменились. Опечатки самого источника не исправляются догадками. Пройдены 128 тестов и 60 прежних автоматических сценариев. Первый полный контроль из 70 вопросов завершён, вручную проверен и дал 34 полных подтверждённых ответа. ## Уже внесённые исправления

- Общие утверждения модели вроде «документ не уточняет условия» не публикуются как установленный факт, если они не подтверждены самим фрагментом. Остальной ответ сохраняется; если после удаления ничего не осталось, ограничение формулируется относительно найденных фрагментов, а не всего документа.
- Квалификация, название и срок обучения при явном коде специальности извлекаются из реальных полей страницы СПК. Готовые значения для специальностей в коде не зашиты. Ссылка указывает на опубликованный источник и содержит извлечённую цитату.
- Разные варианты срока или квалификации на странице не замалчиваются. Согласованная квалификация остаётся доступной даже при расхождении сроков; для спорного поля выводятся варианты и необходимость уточнения базы образования/учебного плана.
- Загрузчик использует название файла из соседней ячейки таблицы вместо общей подписи «Скачать (DOCX)». Это устраняет конкретную причину пропуска документов о поступлении.

На четырёх вопросах разработки о специальностях исходная версия дала три содержательных ответа и один отказ. После исправления получены четыре точных ответа из полей страницы, включая квалификацию 12.02.10. Два старых сценария названий специальностей также проверены. Обнаружены содержательные риски: файл с подписью перечня документов СПК содержит формулировки о бакалавриате/специалитете; на странице специальностей встречаются различающиеся варианты отдельных полей. Нельзя автоматически объединять такие сведения или выбирать удобное число. Действующие суммы стипендий, календарная привязка типа недели и точный разбор расписания также требуют подтверждения.
