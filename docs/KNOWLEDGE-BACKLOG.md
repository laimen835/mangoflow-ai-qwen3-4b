# Как расширять базу СПК

Приоритеты вытекают из вопросов студентов и проверки 60 сценариев. Данные брать с официальных страниц СПК и из утверждённых локальных документов. Обучать модель на изменяемых правилах приёма не требуется: их нужно обновлять в базе.

| Приоритет | Материал | Что сейчас мешает полноценному ответу |
|---|---|---|
| 1 | [Перечень документов для поступления](https://ncsa.ru/institutes/spk/postupayushchim-v-spk/Perechen_dokum_2026.pdf) | В базе есть ссылка на перечень; нужен проверенный текст самого PDF. |
| 1 | [Правила и сроки приёма](https://ncsa.ru/institutes/spk/postupayushchim-v-spk/) | На странице встречаются ссылки разных лет. Для сроков нужен документ с явно указанным учебным годом. |
| 1 | Календарь числителя/знаменателя | Нужна подтверждённая дата понедельника, тип недели и источник правила; OCR календаря этого не подтверждает. |
| 1 | Расписания и замены | PDF импортированы. Для точных пар нужна проверенная таблица «группа — дата — пара — преподаватель — аудитория» и отдельный источник замен. |
| 2 | Стоимость и договор | Найти актуальный приказ о стоимости по специальностям и формам обучения; дата публикации страницы не заменяет год действия приказа. |
| 2 | Общежитие | Общая информация есть. Добавить правила заселения, контакты, стоимость, перечень документов и актуальное количество мест. |
| 2 | Стипендии | Виды упомянуты; добавить действующее положение, размеры, условия и порядок обращения. |
| 2 | Специальности | Добавить отдельные утверждённые карточки: код, квалификация, срок, база 9/11 классов, бюджет/договор, вступительные испытания. |
| 3 | Контакты подразделений | Сверить телефоны, кабинеты, часы работы и назначение контакта: колледж, комиссия, отделение, общежитие. |

Для каждой записи сохранять официальный URL, дату проверки, год действия, способ извлечения и признак ручной проверки OCR. При ошибке загрузки сохранять предыдущую версию, показывая ошибку обновления в портале.

Тестовые записи остаются в базе для разработки и отображаются с пометкой «ТЕСТ», но исключены из поиска для пользователей. Отсутствие документа означает отсутствие подтверждения, а не отсутствие самого факта.

Дальнейшее улучшение поиска: собрать реальные вопросы без персональных данных и оценить русскоязычную/многоязычную embedding-модель на этом наборе. Смену embeddings проводить отдельно, с полным переиндексированием и сравнением результатов. Текущую размерность индекса не менять автоматически.
