# Первый контроль качества по семи темам

**Цель не достигнута: 34/70 полных подтверждённых ответов, 48,6%. Требуется минимум 63/70.** Проверялась изолированная копия, не основная программа. Материалы — зафиксированный официальный снимок; текущие суммы и индивидуальные гарантии из него не выводятся.

## Что проверено

По десять вопросов на каждую тему. Код и 33 документа/684 фрагмента не менялись в процессе; все 70 диалогов отдельные. Эталоны содержат официальный адрес, цитату и страницу/раздел. Визуально проверены нужные таблицы и сканы. Пять вопросов с недостаточным источником оставлены в знаменателе.

| Тема | Полные подтверждённые ответы |
|---|---:|
| Поступление | 4/10 |
| Специальности | 10/10 |
| Преподаватели и контакты | 6/10 |
| Расписание и календарь | 4/10 |
| Стипендии и материальная поддержка | 3/10 |
| Общежитие | 1/10 |
| Сервисы колледжа | 6/10 |

11 ответов частичны или содержат ошибки. Ещё 20 не дают ответа, хотя подтверждение есть в проверенных материалах; часть этих документов/страниц пока не допущена в рабочий поиск. У пяти вопросов недостаточно источника: точный старт II семестра, две рублёвые ставки стипендий на ноябрь 2026, адресат заявления на заселение и срок внесения платы из недоступного порядка оплаты.

При оценке не требовалась дословная фраза эталона. Например, три явно перечисленные пары засчитаны как ответ о количестве. Данные таблицы «Интернаты: 0» засчитаны как ответ о опубликованных местах; они не объявлены свободными местами. Два предложенных человека при заданном полном имени посчитаны частичным ответом. Уточнение об отсутствии дополнительных библиотечных данных трактовалось только относительно переданного фрагмента. Эти решения явно сохранены в поэлементной оценке.

## Основные причины

- **Маршрутизация атрибута.** Вопрос о степени директора получает имя. Запрос об опорной дате не распознаёт склонённые слова «числителя/знаменателя». Вопросы о документах общежития и регламентах колледжа получают неуместное уточнение о поступлении.
- **Поиск и смысл запроса.** Не находятся существующие факты о поступлении после 11 класса, руководителе отделения, поддержке при рождении ребёнка, волонтёрской деятельности. Справочник групп не используется для выбора отделения расписания.
- **Подготовка/допуск данных.** Проверена лишь одна страница точного расписания; ещё нужны другие страницы, варианты дробной записи и подтверждённые факты календаря. У положения о материальной поддержке не допущены раздел поощрений и приложение заявления. Текст положения общежития и дополнительные поля его таблицы не доходят до ответа.
- **Неполнота генерации.** Теряются исключения для порталов и творческого приёма, условие признания иностранного образования. Излишнее сокращение перечня также считается ошибкой.
- **Смешение понятий.** Совет СПК подменяется Учёным советом Академии; все студенческие кружки называются спортивными/самоуправлением; служебная оценка актуальности приписывается документу. В одном ответе о платном приёме указан номер источника о медосмотрах.

Нужен общий поиск по проверенным полям и разделам с сохранением условий и происхождения. Добавлять готовые ответы под номера тестов или просто наращивать промпт нельзя. Ожидаемые факты в `tests/eval/` используются только проверочными скриптами; основной чат их не читает.

## Остальные проверки и задержки

128 тестов проходят. Прежние 60 автоматических сценариев проходят 60/60, однако они проверяют преимущественно фразы/адреса и не заменяют этот контроль. В 14 проверках границ возможностей не наблюдалось раскрытия действующего ключа или выдумывания чувствительных значений; подходящий ответ получен в 10/14, четыре ошибки маршрутизации остаются.

Прогретый p95 поиска на RAG-запросах — около 96 мс. p95 первого текста по всем 70 вопросам — 9,684 с, полного ответа — 14,070 с. Это точечные измерения на данном компьютере; скорость поиска и время генерации — разные показатели. Ранее наблюдавшиеся длительные холодные загрузки модели не скрываются этими прогретыми измерениями.

## Воспроизводимость и дальнейшая приёмка

Сохранены контрольные суммы кода/корпуса, все ответы, задержки, ручная поэлементная оценка и отдельные проверки границ возможностей. Защищённое воспроизведение поиска совпало с источниками и фрагментами всех 49 RAG-ответов. Оно не доказывает внутренний ход рассуждений модели. Полного исходного контроля до изменений нет; приписывать показателю 48,6% размер улучшения нельзя.

Контрольные вопросы видел автор эталонов при проверке источников, ответы модели до завершения не использовались для настройки. Это ограниченная проверка на отложенных ответах, не полностью слепое исследование и не статистическая гарантия для любых вопросов студентов.

Теперь этот набор используется для исправления ошибок и регрессий. Нужна новая зафиксированная контрольная часть с другими фактами, а не только перефразировками. Основная база и модель не переключены, публичный доступ выключен. Исходные ответы/базы/файлы моделей остаются на D; в Git сохраняются код, вопросы, проверенные публичные цитаты и безопасная оценка.
