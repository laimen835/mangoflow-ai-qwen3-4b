# Передача разработчику, 17.11.2026

Это полные исходники приложения Qwen3 4B, а не ссылка на работающий сайт.
Основной режим: multi_query + rerank + source_quotes, Nomic 768, think=false,
context=4096. Отдельный opt-in crawler выключен, автообновление выключено.

Сначала изучить API ChatService, document_policy, retriever, dialogue_context,
query_interpretation и source_quotes; сохранять JSON и NDJSON контракты.
Сохранять оригинальное Message.content, а интерпретацию отдельно в usage.
Не подменять область образования, подразделение или год; score не вероятность.
Не принимать инструкции из документов за команды модели.

Приоритеты доработки по реально выполненным проверкам:
1. Поиск нужных сведений о приёме: сведения часто есть в БД, но не попадают в контекст.
2. Общие контакты/директор не должны заменять контакты приёмной комиссии.
3. Сохранение темы коротких уточнений, особенно тарифы и часы работы.
4. Передача ограничений источников: основной/дополнительный приём, бюджет/платно,
   граждане РФ/иностранцы, СПО/ВО и актуальный год.
5. Проверенная загрузка недостающих документов; заголовок PDF не доказывает его содержание.

Не подгонять ответы под IDs регрессий. После изменения нужен новый контроль;
известные вопросы уже просмотрены. Код 9B не требуется для основной 4B версии;
клиент поддерживает выбор модели конфигурацией. В архиве проверок есть исторические
пути из отдельного 9B checkout, это путь тестового окружения, не зависимость приложения.

Необходимые внешние материалы для воспроизведения именно рабочей базы:
проверенный снимок PostgreSQL без conversations/messages, подходящие файлы storage,
GGUF Qwen3 4B с закреплённым SHA256, Nomic и локальная модель mMARCO reranker.
Они остаются у владельца и не включены в публичный Git. Для пустого стенда модель
и знания подключаются отдельно; нельзя обещать ответы текущей демонстрации без них.

Опубликованная копия отличается от исходной только безопасными шаблонами,
удалением пароля из default DATABASE_URL, документацией передачи и эквивалентной
записью отрицательной URL-фикстуры в тесте. Секретная история не перенесена.
