# Доступ к помощнику через интернет

Двойной щелчок по `Run-SPK.cmd` запускает приложение и доступ для гостей через ngrok. Открывается консоль «Помощник СПК — запуск и ссылки» с локальным адресом, внешней ссылкой и состоянием приложения, базы и Ollama. На рабочем столе создан ярлык «Помощник СПК».

При первом запуске требуется бесплатный аккаунт ngrok: откроется страница Your Authtoken. Значение токена вставляется в скрытое поле консоли. `setup-ngrok.ps1` сохраняет его в `D:\Codex-RAG-runtime\ngrok\ngrok.yml`, вне репозитория, с доступом только владельцу, администраторам и SYSTEM; токен не передаётся через аргументы процесса и не выводится в консоль. Явный путь `--config` также поддерживает установленную из Microsoft Store версию агента. После подключения аккаунта используется выданный ему постоянный dev-домен. При следующих запусках повторный ввод не нужен. На бесплатном тарифе посетитель может увидеть страницу ngrok с кнопкой Visit.

В консоли: `S` отключает внешний доступ, `Q` закрывает панель, оставляя приложение работающим. Проверка доступности повторяется примерно каждые 15 секунд; при отключении доступа панель не включает его автоматически. Адрес сохраняется в `logs/share-url.txt`. Параметр `Run-SPK.cmd -LocalOnly` запускает локальное приложение без создания нового внешнего доступа.

Ссылку можно отправить другим людям. Компьютер, локальный сервер и интернет-соединение должны оставаться включёнными. `start-ngrok.ps1` подключает ngrok только к отдельному гостевому шлюзу на 127.0.0.1:8001, с отключённой записью запросов в инспектор агента. Прямого доступа к Ollama, PostgreSQL и локальному административному API нет. Локальный API ngrok слушает 127.0.0.1:4040.

- `start-ngrok.ps1` запускает приложение и ngrok без постоянной панели. Пока собственный агент работает, повторный запуск использует его.
- `start-share.ps1` оставлен для прежнего временного доступа localhost.run; обычный ярлык использует ngrok. После подтверждения новой ссылки старый SSH-туннель отключается.
- `stop-share.ps1` отключает публичный доступ; локальное приложение остаётся работать.
- При создании нового туннеля ссылка меняется. Для передачи участникам используйте адрес из действующей консоли.

Постоянное имя ngrok сохраняется за аккаунтом, но доступ зависит от работающего агента, компьютера, интернета и лимитов бесплатного тарифа. [Документация ngrok](https://ngrok.com/docs/pricing-limits/free-plan-limits). Бесплатные адреса старого localhost.run могут меняться.

Гостевые сеансы отделены от локальных диалогов: предоставленный браузером UUID отображается в новый внутренний UUID. Другой посетитель не может прочитать этот диалог. Внешние административные маршруты и документация API закрыты; тестовые и локальные документы скрыты из списка и скачивания.

Состояние гостевых сеансов хранится в памяти шлюза до 24 часов. Перезапуск шлюза сбрасывает привязку гостя к истории, но не удаляет записи из локальной базы. Не используйте этот пробный режим для хранения чувствительных переписок.

Ограничения нагрузки: два обрабатываемых вопроса одновременно, до 20 вопросов за 10 минут на гостя, до 120 за 10 минут на весь шлюз. Ответы зависят от скорости вашего компьютера.

Проверено: 49 тестов проекта прошли; живая HTTPS-проверка страницы, ответа Ollama, потока, собственной истории, изоляции посетителей, блокировки администрации и скрытия локальных файлов — 10/10. Результаты в SHARE-CHECKS.json.

Cloudflare Tunnel в текущей сети не подключился. Активный доступ работает через встроенный OpenSSH и localhost.run; брандмауэр, DNS и параметры безопасности Windows не менялись.
