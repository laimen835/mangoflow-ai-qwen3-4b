# Пробный перенос на CPU-сервер

Приложение восстановлено на Ubuntu 24.04, 4 vCPU / 16 ГБ RAM / 80 ГБ NVMe. PostgreSQL, Ollama и API запущены.
Проверены точные digest Qwen3 4B Instruct и Nomic: совпадают с исходной установкой.
В копии базы 78 документов и 1501 фрагмент. API привязан к loopback; публичный доступ не включён.

## Измерения

Вопросы выполнялись последовательно через приватный SSH-туннель, без параллельной нагрузки теста. Первый вопрос измерен отдельно, последний повторяет его после прогрева. Шесть запросов не являются статистически достаточным исследованием p95 или общей точности.

| Вопрос | ПК: первый текст / всего, с | Облако: первый текст / всего, с |
|---|---:|---:|
| Какие направления подготовки есть в институте цифровых технологий? | 29.695 / 32.322 | 54.54 / 85.146 |
| Какие документы нужны для поступления в СПК? | 9.939 / 12.181 | 37.412 / 61.468 |
| Как оформить материальную помощь в СПК? | 6.892 / 9.684 | 32.604 / 106.249 |
| Кто директор института цифровых технологий? | — / 0.019 | — / 0.087 |
| Кто был директором института цифровых технологий в 1990 году? | 8.387 / 8.641 | 32.262 / 35.052 |
| Какие направления подготовки есть в институте цифровых технологий? | 6.989 / 9.648 | 33.1 / 63.166 |

## Вывод и ограничения

- Повтор одного и того же вопроса: 63,166 с в облаке против 9,648 с на ПК, примерно в 6,5 раза медленнее.
- Первый текст в прогретых генеративных запросах появляется примерно через 32–37 с.
- Записанный приложением поиск занимает 0,17–0,99 с; основная задержка приходится на этап LLM. Конкретная роль CPU, квот и обработки промпта отдельно не профилировалась.
- Быстрый ответ о директоре идёт из карточки базы, а не через генерацию LLM. Он не доказывает высокую скорость модели.
- Вопрос о 1990 годе обработан отказом без подстановки директора другого подразделения.
- Ответ о документах для поступления всё ещё даёт ссылку на перечень вместо самого списка. Это ограничение присутствовало в исходной локальной версии.
- Для остальных ответов возвращены тематические официальные ссылки; это не заменяет проверку каждого утверждения по тексту источника. Общая точность по всем темам не оценивалась.

Перенос технически успешен, но текущая скорость генерации неудобна для интерактивной демонстрации. Продолжение недельной аренды и публичный запуск не выполнены автоматически по результатам этой пробы.
